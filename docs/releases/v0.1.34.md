## Highlights

- Members can set an optional profile title. It appears beside names in the people
  directory, the channel members dialog, and message author headers. Edit your own
  title from Preferences.
- Messages that already have a thread now show an always-visible reply count beneath
  them ("1 reply" / "3 replies"). Clicking it opens the same thread pane as the hover
  control. Messages with no replies stay unchanged, and the hover control still starts a
  new thread.
- Channels can accept incoming webhooks. Enabling one provisions a bot member for that
  channel; posts arrive from that bot like any other agent message. The webhook URL is
  shown once, posts only to its own channel, and disabling the webhook immediately
  invalidates the old URL.

## Fixes

- Retracting a message while you are online now updates the live desktop view the same
  way a refresh would: unread and mention counts drop, the sidebar preview falls back to
  the newest surviving message, reactions on the retracted message clear, and thread reply
  counts update. Retracting a thread root removes that thread summary.
- Packaged Linux AppImage builds register a user-level `hype-comms://` handler on startup
  so WorkOS browser sign-in can return to the app. The `.deb` path verifies the existing
  system handler. When the scheme is confirmed unbound, the sign-in card explains that
  browser sign-in cannot return and how to fix it.
- Failures starting WorkOS sign-in now show the underlying Chromium `net::ERR_*` token on
  the sign-in card instead of a generic message, so SSL and connectivity problems are
  diagnosable without digging through logs.

## Known limitations

- There is no desktop UI yet for enabling, rotating, or disabling channel webhooks. Those
  actions use the server API.
- Protocol-handler registration and the unbound-scheme warning apply only to packaged
  Linux builds. macOS and Windows keep their existing handler behavior.
- If `xdg-utils` is missing, the Linux probe reports unknown and stays quiet rather than
  showing a false unbound warning.
