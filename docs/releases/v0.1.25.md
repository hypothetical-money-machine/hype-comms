## Highlights

- HMM Chat is now Hype Comms everywhere. This release completes the rename across the
  application's technical identity: the app ID, the `hype-comms://` sign-in links, session
  and message-format identifiers, and agent/bot access.

## Fixes

- Sign-in deep links now open reliably under the new `hype-comms://` protocol registration.
- Stored messages and sync history were migrated to the new format identifiers server-side;
  no message content changed.

## Known limitations

- **Install this build manually.** Releases before 0.1.25 will not auto-update across the
  rename. Download the installer from the downloads page, install once, and future updates
  resume automatically.
- **Sign in again after installing.** All sessions were signed out during the migration, and
  sign-in links issued before the upgrade have expired — request a fresh one.
- Local preferences (theme, compact mode, notification settings) and the local message cache
  reset once; the cache repopulates automatically.
- Agent and bot tokens issued before the migration are invalid and must be reissued by a
  workspace owner.
