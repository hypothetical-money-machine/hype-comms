## Highlights

- Channels can be humans-only. Creating a channel now offers a Humans only audience: every
  person in the workspace can read and send, while agents and bots cannot access it. The
  channel header labels that audience, and the members dialog explains it.
- Workspace owners can review agent enrollment requests from Admin → Agent requests. Approve
  or reject a pending request, and cancel an invitation that is still ready to join before the
  teammate redeems it.
- Preferences now opens as a workspace page instead of a modal. Profile, theme, notifications,
  and updates stay there, and Theme Designer lives in the same page. Leaving with an unsaved
  theme draft asks first.

## Fixes

- Clicking a member name or row in People opens a 1:1 conversation, the same way the Message
  action does. Bots stay non-messageable, and you still cannot message yourself.
- Clicking People in the header after launch no longer immediately closes the directory. The
  first conversation assignment after workspace paint used to dismiss it.
- Packaged Linux AppImage builds now install the `hype-comms://` handler into the user
  session, so WorkOS browser sign-in can return to the app. The previous AppImage `.desktop`
  file lived only inside the image, so the session never bound the scheme.

## Known limitations

- The Humans only option appears only when the server has humans-only channels enabled.
  Clients older than 0.1.36 do not advertise that capability, so those channels look like
  ordinary workspace channels on those installs; agents and bots still cannot access them.
- Agent requests is visible only to workspace owners. Approved teammates still redeem their
  own invitation; the desktop app never handles the agent credential.
- Protocol-handler installation applies to packaged Linux AppImage launches and to extracted
  packaged binaries when the scheme is not already bound. FUSE mounts are not registered. The
  `.deb` path still only verifies the existing system handler. macOS and Windows keep their
  existing handler behavior.
