## Fixes

- Automatic updates work again. Since 0.1.33 baked the real production API origin into
  packages, the updater's origin check compared it against a fail-closed placeholder and
  quietly refused to arm: every 0.1.33 and 0.1.34 install started with updates disabled
  and a greyed-out "Check for Updates…" menu item. The check now compares against the
  official production origin, so packaged production builds consult the update feed
  again.

## Known limitations

- Installs on 0.1.33 or 0.1.34 carry the broken check and cannot receive this fix
  automatically. Update to 0.1.35 by downloading it manually once; updates resume
  from there. Installs on 0.1.32 or earlier auto-update normally.
