## Highlights

- The message composer has a formatting toolbar and keyboard shortcuts for bold, italic,
  strikethrough, inline code, links, bulleted and numbered lists, and quotes. Drafts stay
  Markdown; the toolbar wraps the selection with the same markers the app already renders.
- Attach several files in one picker selection, up to 10 per message. If a later file fails,
  files that already uploaded stay on the draft and the error is shown.
- The exchange-loop logo replaces the placeholder H on the sign-in card and workspace rail, and
  is the application icon in the Dock or taskbar, installers, and native notifications.

## Known limitations

- The composer is still a Markdown textarea, not a WYSIWYG editor: you see the markers in the
  draft. Links must be HTTPS, matching the renderer. Italic uses `*` rather than `_` so wrapping
  a `@username` mention still notifies.
- A selection that exceeds the remaining attachment slots is rejected. Each file is still limited
  to 25 MiB.
