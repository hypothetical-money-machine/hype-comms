## Highlights

- Chat messages now render as Markdown. Headings, emphasis, lists, code blocks, tables, task
  lists, blockquotes, and footnotes show as formatted text in both workspace conversations and
  the local AI Channel. `#channel` mentions still open that conversation when you click them.

## Known limitations

- Raw HTML in a message is shown as literal text and is not interpreted.
- Remote images are not loaded in place; they appear as links instead.
- External links open only for HTTPS destinations without embedded credentials.
