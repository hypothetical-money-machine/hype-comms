## Highlights

- The sidebar now includes a local AI Channel. Choose a folder on this device, start Claude Code,
  and talk with it about that workspace. Claude can explore files, propose edits, and run tools;
  each tool request pauses for Deny, Allow once, or Always allow before anything happens.
- AI Channel stays on this device. It is not a workspace conversation, and other members cannot
  see the chat, the chosen folder, or Claude’s output.

## Known limitations

- AI Channel needs a locally installed, signed-in Claude Code (`claude` on your PATH). If Claude
  Code is missing or not authenticated, the channel explains how to retry.
- The chosen folder is Claude’s working directory, not an operating-system sandbox. Approved tools
  and your Claude settings may also reach files outside that folder.
- AI Channel history and folder choice live on this device only and do not sync across machines.
