## Highlights

- Typing `@` in the composer now opens member autocomplete: arrow keys move the highlight,
  Enter/Tab insert, Escape dismisses, and typing filters the list. Inserted and received
  mentions render as chips in the composer, transcript, and pending outbox instead of plain
  text. Message bodies still store the same verified `@username` tokens.
- You can retract your own message within five minutes of sending it. Retracting removes the
  message and its attachments from history, search, and file listings for everyone, and
  clients on 0.1.31 or later hide it immediately. The server enforces the five-minute window
  with its own clock; the control itself appears and disappears based on your device's clock,
  so a badly skewed clock can show it when the server would refuse. Author-only — no owner or
  admin bypass, and no editing.
- Workspace owners get an Admin → Communication paths view showing which active members talk
  to each other: DM counts, shared channels, channel-message volume, and last activity. It
  aggregates metadata only and never reads message bodies.
- Email addresses and `mailto:` links in messages are now clickable and open your operating
  system's mail composer. Malformed or header-injecting values stay inert text.

## Fixes

- Opening a conversation paints immediately from the local cache and then fetches just that
  conversation's first page of history, instead of re-downloading every conversation's history
  first. Opening a DM from a member name no longer triggers a full refresh. A full resync still
  loads every conversation.
- When WorkOS sign-in is enabled, production sign-in no longer rejects valid credentials. The
  server now accepts WorkOS's current opaque `sk_` API keys alongside the legacy
  `sk_live_`/`sk_test_` form, and validates access tokens against the real WorkOS issuer set
  instead of the value pinned by the emulator.

## Known limitations

- Retraction is a five-minute, author-only window. There is still no message editing, and
  messages older than five minutes cannot be removed.
- Clients older than 0.1.31 do not receive retraction events. If someone retracts a message
  while a 0.1.30 client is showing it, that client can keep displaying it until it restarts or
  reloads history. The message is already hidden from server history, search, and file
  listings.
- The Communication paths view is limited to workspaces of at most 25 active members and
  reports at most 300 member pairs.
