## Highlights

- Typing `@` in the composer now opens member autocomplete: arrow keys move the highlight,
  Enter/Tab insert, Escape dismisses, and typing filters the list. Inserted and received
  mentions render as chips in the composer, transcript, and pending outbox instead of plain
  text. Message bodies still store the same verified `@username` tokens.
- You can retract your own message within five minutes of sending it. Retract removes the
  message (and its attachments) from every client's timeline, history, and search. The
  server clock decides the window; after five minutes the control disappears and the message
  stays immutable. Author-only — no owner or admin bypass, and no editing.
- Workspace owners get an Admin → Communication paths view showing which active members talk
  to each other: DM counts, shared channels, channel-message volume, and last activity. It
  aggregates metadata only and never reads message bodies.
- Email addresses and `mailto:` links in messages are now clickable and open your operating
  system's mail composer. Malformed or header-injecting values stay inert text.

## Fixes

- Opening a conversation paints immediately from the local cache and then hydrates only that
  thread, instead of re-downloading every conversation's history first. Opening a DM from a
  member name no longer hesitates.
- Production WorkOS sign-in no longer rejects valid live access tokens: issuer validation now
  accepts the real WorkOS issuer set instead of pinning the emulator's value.

## Known limitations

- Retraction is a five-minute, author-only window. There is still no message editing, and
  messages older than five minutes cannot be removed.
- The Communication paths view is limited to workspaces of at most 25 active members and
  reports at most 300 member pairs.
