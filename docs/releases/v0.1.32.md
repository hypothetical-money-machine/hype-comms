## Highlights

- See when people are online, away, or offline, and see typing indicators in active
  conversations. Presence has no timestamps or history.
- Reopen a previously signed-in workspace when the server is unreachable. Hype Comms restores
  encrypted cached conversations and keeps new messages in the outbox until it reconnects.

## Fixes

- Retracted messages no longer reappear from stale snapshots, history responses, or concurrent
  cache writes. Their notifications, unread state, mentions, attachments, and thread summaries are
  also cleared.
- Deep-link sign-ins now ask before replacing the current session. Cancelling the prompt, opening
  an expired link, or receiving an incomplete authentication callback no longer signs out the
  current user.
- Cancelling a quit during authentication no longer leaves the sign-in state unusable.
- Sign-in throttling now separates unrelated clients and magic-link recipients, preventing one
  person's attempts from using another person's allowance.

## Known limitations

- Offline reopening requires an existing encrypted cache, the same signed-in credential, and
  secure operating-system storage. A first sign-in still requires the server.
- Bots do not report presence, and presence does not include "last seen" history.
