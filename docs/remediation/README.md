Remaining release work is installed-update acceptance on supported platforms, native notification
acceptance where enabled, the actual Hermes framework smoke, production-size backup restoration,
integration of the stack, a fresh unused stable version and final rehearsal, then the scheduled
cutover using deployment access. The local server rollback test covers a separate compatible server
image; compatible installed-client rollback still needs its native evidence. Production has not
been changed. After one successful production release cycle, remove unused capability columns and
transitional readers in a separate migration review. That cleanup is intentionally absent here.
